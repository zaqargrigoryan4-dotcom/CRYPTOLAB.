CRYPTOLAB
=========

Գործարկում
----------
Տարբերակը ստատիկ է և արտաքին գրադարանների կամ backend-ի կարիք չունի։
Առաջարկվող եղանակը՝ բացել cryptolab_site թղթապանակը տերմինալում և գործարկել.

  python -m http.server 8000

Այնուհետև դիտարկչում բացել http://localhost:8000։
Ժամանակակից դիտարկիչ և Web Crypto API պահանջվում են AES-GCM և RSA-OAEP-ի համար։
index.html-ը կարելի է բացել անմիջապես կամ localhost-ով. հավելվածի JavaScript-ը
բեռնում է դասական script, այնպես որ file:// էջերում ES module CORS սահմանափակումը
չի խանգարում մեթոդների ընտրացանկին և կոճակներին։

Մեթոդներ
--------
- Morse՝ միջազգային լատինական/թվային աղյուսակ և հետադարձելի CRYPTOLAB հայերեն
  ընդլայնում։ Տարածված Armenian Unicode punctuation-ը և չճանաչված Unicode նիշերը
  կոդավորվում են ընդլայնման միջոցով։
- Binary (UTF-8), ASCII, Unicode/UTF-8 hex և Base64։
- Caesar, Vigenère (լատիներեն, հայերեն կամ երկուսի ռեժիմ), Atbash։
- Իրական AES-256-GCM՝ PBKDF2-HMAC-SHA-256 (250,000 iteration), պատահական 16-byte
  salt, պատահական 12-byte nonce և GCM authentication tag։
- Իրական RSA-OAEP՝ 2048-bit բանալիով և SHA-256-ով։ Բանալիները գեներացվում են
  դիտարկչում և ներկայացվում են JWK JSON ձևաչափով։ RSA-ն սահմանափակ հաղորդագրության
  չափ ունի. երկար տվյալների համար օգտագործեք AES-GCM։
- Յուրաքանչյուր մեթոդի ուսուցողական էջից «Փորձել կոդավորումը» և «Փորձել
  վերծանումը» կոճակները բացում են գործիքը՝ համապատասխան գործողությամբ և
  փորձնական տվյալով։ AES/RSA օրինակները ստեղծում են ժամանակավոր տեղային բանալիներ։
- Փոխակերպիչում «Կոդավորել / Գաղտնագրել» և «Ապակոդավորել / Վերծանել» կոճակներն
  ուղղակիորեն գործարկում են ընտրված գործողությունը։

Հայերեն աջակցություն
--------------------
Կոդավորիչը չի տառադարձում հայերենը։ Caesar և Vigenère մեթոդներն ունեն 39 տառանոց
հայերեն այբուբենի առանձին ռեժիմ՝ մեծատառ/փոքրատառ պահպանմամբ։ «ԵՎ»-ը դիտարկվում է
որպես 39-րդ տառի մեծատառ ձևը։ Կետադրությունն ու բացատները չեն փոխվում։
Morse-ի հայերեն քարտեզը կայքի հետադարձելի ընդլայնումն է, ոչ թե միջազգային ստանդարտ։

Գաղտնիություն և սահմանափակումներ
--------------------------------
- Հաղորդագրությունները, գաղտնաբառերը և գաղտնի բանալիները սերվեր չեն ուղարկվում։
- Տեղային պատմությունն անջատված է լռելյայն. միացնելիս պահվում են միայն մեթոդը,
  գործողության տեսակը և ժամը, ոչ թե հաղորդագրությունը կամ գաղտնաբառը։
- AES գաղտնաբառը չի պահպանվում։ Պահպանեք այն ապահով տեղում. այն հնարավոր չէ
  վերականգնել։ Սխալ գաղտնաբառը կամ փոփոխված ciphertext-ը չի անցնում tag-ի ստուգումը։
- RSA գաղտնի բանալին չպետք է կիսել կամ պահել անպաշտպան տեղում։ Գործիքը ցուցադրում է
  JWK-ը, որպեսզի օգտատերը կարողանա ինքնուրույն պահել/փոխանցել բանալին։
- Caesar, Vigenère, Atbash, Morse, ASCII, Binary, UTF-8 և Base64-ը ժամանակակից
  գաղտնիություն չեն ապահովում։
- Ադմինի ցուցադրական գաղտնաբառը `morze` է և տեսանելի է frontend կոդում։ Վահանակը
  միայն տեղային ցուցադրական վիճակագրություն է, իրական authentication չէ։
- Սա կրթական նախագիծ է, ոչ production-ready կամ անկախ անվտանգության աուդիտ անցած
  ծառայություն։ Իրական տեղակայման համար անհրաժեշտ են HTTPS, CSP և անկախ աուդիտ։

Թեստեր
------
Node.js 20+ միջավայրում՝ նախագծի թղթապանակից.

  node --test

Թեստերը ստուգում են բոլոր մեթոդների encode/decode round-trip-ը, հայերենի 39 տառը,
մեծատառ/փոքրատառը, Armenian punctuation-ը, երկար Unicode հաղորդագրությունները,
սխալ մուտքերը, AES-GCM սխալ գաղտնաբառն ու փոփոխված ciphertext-ը և RSA-OAEP բանալիները։
